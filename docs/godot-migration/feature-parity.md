# Ma trận parity

Baseline `6836b59`. “Headless” xác nhận hành vi hoặc dữ liệu trong engine. “Web” xác nhận trên Chrome desktop. Một test fixture networking xác nhận giao tiếp thực với backend và được ghi riêng với kiểm thử UI game đầy đủ.

| Hệ thống gốc | Phần đã port | Tiêu chí và bằng chứng | Còn mở |
|---|---|---|---|
| Boot, menu, flow, input | Scene chính, màn menu, Settings, pause/resume, restart, result, bindings nguồn | Headless `traversal_gameplay`, `game_flow`. Web boot, Training/Hunt, pause/restart và Settings | Đánh giá focus, bố cục ở kích thước và browser khác |
| Valkenburg | Layout chung, collider gốc, nhà mái dốc, façade, tường, tháp, depot, cây MultiMesh và vòng | Headless `world_test` kiểm tra kích thước, mặt collider, metadata grapple, depot/ring. City được render trong Web. | So sánh ánh sáng, vật liệu và culling ở nhiều góc máy |
| Camera, locomotion, physics | Capsule, 60 Hz, di chuyển theo camera, chạy, nhảy, dodge, FOV theo tốc độ và tránh vật cản | Headless `traversal_smoke`, `game_flow`. Web chuyển drill qua input | Cảm giác điều khiển, số liệu jitter/tunneling với frame stall và lộ trình dài |
| Hai dây ODM | Raycast/assist, khóa zone, neo Titan di động, retry, reeling, swing, gas, momentum, thả dây | Headless `traversal_smoke` đối chiếu công thức TS trong `1e-5`, kiểm tra world collision và occlusion. Web đã bắn đồng thời Z/X. | Trace đầu-cuối Rapier/Godot trên cùng route và nhiều RTT |
| Rig và animation | Vanguard và 3 Titan từ mesh, skin, bone, clip gốc cùng AnimationTree, pose layering và socket vũ khí | Headless `bake-rigs-check` xác minh 48 clip, 25 socket, 5 pose trong 8 mm. `traversal_smoke` kiểm tra kiếm khi chạy clip | Playtest các transition, pose tay, chân và hoạt ảnh Titan bị thương |
| Kiếm | Timing light/heavy, lunge, sweep 2 kiếm, spin, crit phía sau, combo, mòn/thay lưỡi, hit-stop solo | Headless `combat_test` kiểm tra sweep, góc Nape, damage theo tốc độ và kiếm cùn. `game_flow` bấm F hạ Titan từ phía sau và kiểm tra mòn kiếm, tính kill. | Kiểm tra trực quan chuỗi tấn công, bóng và feedback ở mọi zone |
| Thunder Spear | Ammo/cooldown, aim assist, đường bay, va chạm thành phố, trực tiếp/AoE, stun và FX | Headless main test kiểm tra input và ammo, WASM/Colyseus fixture xác nhận fired/exploded chính thức | Đối chiếu toàn bộ quỹ đạo solo và va chạm mục tiêu di động |
| AI Titan | 3 biến thể, idle/patrol/detect/chase, whisker avoidance, melee, anti-air grab, injured/stunned/death, hồi phục limb | Headless `titan_test` kiểm tra AI impact, sáu zone, cripple và death. `traversal_smoke` kiểm tra thoát grab | Route nhiều block, tình huống bị kẹt, lâu dài qua cả hai wave |
| Nhiệm vụ và progression | 5 drill Training, 2 wave Hunt, điểm/rank, fail/retry, settings và progress | Headless `game_flow` xác nhận drill, wave 3+4, pause/restart, chết/kết quả. Web smoke vào Training/Hunt, đọc save cũ và giữ Settings khi reload. | Chạy thắng cả hai mode bằng tay và xác nhận lưu điểm qua lần mở lại |
| Matchmaking và phiên | Public list, tạo/phòng mã, ready/start, leave, reconnect token | Hai game Web qua UI lobby, vào trận, restart từ menu đội trưởng và rời trận. Restart tạo roster Titan mới và đặt lại ammo cho cả hai. Fixture WASM thử reconnect token mà không tạo thêm người chơi. | Production proxy HTTPS/WSS, tải 4 người |
| Authority và replication | Input/attack intent, ACK từng móc, prediction/replay, Titan snapshot, avatar/rope nội suy, server projectile, down/revive | Headless `network-interpolation`, `traversal_smoke`. 2-WASM fixture xác nhận movement ACK, quick chat và spear. | So sánh live Godot ↔ Three.js và kiểm tra 50/100/200 ms RTT, revive toàn trận |
| HUD và tactical | Health/gas/blade, ODM reticle, gear, hướng dẫn, lock HP, map, lobby roster, ping/quick-chat, debug | Headless scene flow, HUD Web và quick chat qua hai game Web. Ping và squad status dùng snapshot. | Độ đọc khi 4 người / nhiều ping, chi tiết marker và phong cách visual so với giao diện web gốc |
| Audio, VFX, graphics | 15 SFX PCM, VFX pool giới hạn, slash/impact/steam, spear, gas trail, lights/shadows và preset | Headless `feedback` kiểm tra tín hiệu, giới hạn pool và mesh. Web render đã được quan sát | Nghe thử mức âm lượng, ảnh chuẩn hóa và full-device profiling |
| Build | Godot Web một luồng, macOS ZIP, build scripts và hướng dẫn host | Web release chạy Chrome, native ZIP xuất thành công | Browser matrix và cài đặt macOS từ ZIP trên máy sạch |
